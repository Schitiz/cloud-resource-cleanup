# GCP-4 pending bugs

Quirks of the GCP Spot VM cleaner (`crc/gcp/spot_vm.py`, now `crc/gcp/spot_vm/`) found in rung GCP-4. None is fixed; each has a case in `tests/test_gcp_spot_instances_parity.py`. Line numbers are `main` (`git show main:crc/gcp/spot_vm.py`). SAF-006..013 age gates, SAF-039 (leftover disks), SAF-041, SAF-043..045 apply.
