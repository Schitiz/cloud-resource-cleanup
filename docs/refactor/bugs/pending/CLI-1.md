`docs/refactor/BUGS.md`; the ID column is `NEW` until the integrator assigns `BUG-NNN`. Locations
are on `main`, verified with `git show main:crc.py`. All behaviour is preserved and pinned by
`tests/test_cli_args_parity.py`; nothing is fixed here.
