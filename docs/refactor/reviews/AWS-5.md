## Coding summary

Rung AWS-5: `crc/aws/spot_instance_requests.py` refactored into the subpackage `crc/aws/spot_instance_requests/` with a registered `Cleaner` (`@register("aws", "spot_instance_requests")`), no behaviour change.

- **Summary.** `SpotRequestCleaner` (`cleaner.py`): `plan()` lists regions and requests and filters (only describe calls); in a dry run `plan()` also runs the read-only preview of the real path (`preview.py`) and logs the summary, so a dry run is `plan()` alone. `apply()` does the mutating calls region by region in the order of main (tag, cancel, terminate, wait, delete, then the region sweep) and logs the summary. Split by responsibility (1185 lines on main): `model.py`, `client.py` (SDK Protocol `SpotClient`), `rules.py` (pure decisions via `crc.core.policy`: `filter_tags_glob_all_keys`, `exception_tags_any`, `notags_all`, `aws_spot_has_sensitive_yb_task`, `effective_age`), `requests.py`, `volumes.py`, `preview.py` (reads), `leftover.py`, `cleanup.py` (mutations), `cleaner.py`, `adapter.py`, each at most 292 lines; package README added. Age goes through `crc.core.age` (`validated_retention_age`, `is_old`). `SpotInstanceRequests` keeps its constructor, attributes, `get_deleted`, `delete_count`, `delete()` and the private methods the existing tests call (`_cleanup_one`, `_get_filtered_requests`, `_sweep_tagged_leftover_volumes`, `_scope_tags_for_volume`, class constants) as an adapter; the old import path works through `__init__.py`. `crc.py` is unchanged. Both ratchet lines for the module were removed from `pyproject.toml`; nothing added.
